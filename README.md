Tab Icons
=========

Tab Icons lets editors assign Backdrop icon names to local task tabs using a popup icon browser. Pick an icon on the Tab Icons admin page, save, and icons render alongside tab text.

Requirements
------------

This module needs the core Menu module to be enabled. It also depends on the Menu Icon module for the shared icon picker.

Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.

- Configure icons at Administration > Structure > Tab icons (admin/structure/tab-icons). Pick icons for tabs, optionally hide tab text on small screens, and save. Icons will appear on tabs and local actions where assigned.
